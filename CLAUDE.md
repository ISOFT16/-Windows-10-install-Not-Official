# Правила проекта

## Linoves: версии и кодовые имена (просьба владельца, выполнять всегда)

Каждое обновление Linoves (папка `linoves/`) — это новый выпуск с номером версии и кодовым именем.

- Текущий выпуск: **1.2 (C3)**.
- Название системы: **Linoves** (до 1.2 называлась RustOS).
- Каждое следующее обновление: кодовое имя +1 (C2, C3, C4, ...), версия +0.1 (1.1, 1.2, 1.3, ...).
- При выпуске обновления:
  1. `linoves/Cargo.toml`: поле `version` (например, `1.1.0`).
  2. `linoves/src/main.rs`: константа `CODENAME` (например, `"C2"`).
  3. `linoves/CHANGELOG.md`: новый раздел сверху, `## 1.1 (C2)`, со списком изменений.
  4. Пересобрать ISO: `./scripts/make-iso.sh` (обновит `linoves/dist/Linoves.iso`).
  5. Обновить строку «Текущий выпуск» в этом файле.
- В ответе пользователю и в сообщении коммита **всегда** писать версию и кодовое имя,
  например: «Linoves 1.1 (C2)».

## Linoves: внешний вид делает владелец

Внешний вид (рабочий стол, значки, окна, цвета) рисует владелец проекта сам.
Не придумывать и не менять дизайн по своей инициативе: брать его из рисунков
владельца (`linoves/theme/desktop.png` -> `tools/gen_theme.py`) и программировать
только механику (что где нажимается). Если для чего-то рисунка нет — спросить.
