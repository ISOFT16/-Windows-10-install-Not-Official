# История версий RustOS

Каждое обновление получает номер версии и кодовое имя: C1, C2, C3, ...

## 1.0 (C1)

Первый выпуск.

- 64-битное ядро на Rust: загрузка через Multiboot (QEMU `-kernel` или GRUB).
- Защита: обработчики всех 256 прерываний, отдельные стеки для аварийных исключений,
  защитная страница стека, неотображённая нулевая страница, проверки кучи,
  обнаружение взаимоблокировок, аварийный экран с отчётом.
- Драйверы: экран VGA, клавиатура PS/2, COM1, таймер PIT, контроллер прерываний 8259.
- Командная оболочка с историей и Tab-дополнением, RAM-диск, калькулятор.
- 11 встроенных самотестов (`selftest`).
- Готовый загрузочный образ `dist/RustOS.iso`.
