# MicroOS

> **Новое: [RustOS](rustos/)** — настоящая 64-битная операционная система на Rust, которая
> загружается без Linux/Windows (в QEMU или на реальном ПК). Запуск: `cd rustos && cargo run --release`.


**MicroOS** — учебная операционная система на Python. Её можно установить на Android как APK-приложение или запустить в терминале на компьютере.

Это симулятор ОС, который работает поверх Python. Внутри него есть:

- **ядро** с таблицей процессов и кооперативным планировщиком (round-robin в отдельном потоке);
- **менеджер памяти** со страницами по 4 КБ (16 МБ виртуальной памяти);
- **виртуальная файловая система** с каталогами, владельцами файлов и правами; она сохраняется на «диск» и не пропадает между запусками;
- **пользователи** `root` и `user` с паролями (`su`, `useradd`, `passwd`);
- **командная оболочка msh**: больше 60 команд, конвейеры `|`, перенаправление `>`/`>>`, цепочки `;`, переменные `$VAR`, история, Tab-дополнение;
- **текстовый редактор** `edit`, калькулятор `calc`, запуск Python-скриптов `py`;
- **фоновые программы**: `clock`, `counter`, `primes`, `memhog`, `logger`, `spinner`.

## Установка на Android (APK)

APK собирается автоматически на GitHub (вкладка **Actions**, workflow «Сборка APK»):

1. Откройте репозиторий на GitHub, вкладка **Actions** → последний запуск «Сборка APK».
2. Внизу, в разделе **Artifacts**, скачайте `MicroOS-apk` (это zip, внутри файл `.apk`).
3. Перенесите `.apk` на телефон и откройте его. Android попросит разрешить установку из неизвестных источников: разрешите.

Если создать тег вида `v1.0.0`, APK также появится на странице **Releases**, откуда его удобно скачивать прямо с телефона.

Первая сборка идёт около 20–30 минут (скачиваются Android SDK и NDK), следующие быстрее благодаря кэшу.

### Сборка APK вручную (Linux / WSL)

```bash
pip install buildozer "cython<3.1"
sudo apt install -y openjdk-17-jdk git zip unzip autoconf libtool pkg-config zlib1g-dev cmake libffi-dev libssl-dev
buildozer android debug        # APK появится в папке bin/
```

## Запуск на компьютере

```bash
python -m microos          # консольная версия (нужен только Python 3.10+)
pip install kivy && python main.py   # графическая версия, как на телефоне
```

## Первые шаги

```
help              список всех команд
neofetch          сведения о системе
ls -l, tree /     посмотреть файлы
edit заметка.txt  редактор (:w — сохранить, :q — выйти)
py hello.py       запустить Python-скрипт внутри MicroOS
run clock         запустить фоновый процесс
ps / top          список процессов,   out 2 — вывод процесса,   kill 2 — остановить
free / df         память и диск
su                стать root (пароль по умолчанию: root)
cat f | grep x | wc   конвейеры
reboot / shutdown
```

На телефоне под строкой ввода есть панель: **Tab** (дополнение), **↑ ↓** (история), **Ctrl+C** (отмена), **A− / A+** (размер шрифта).

## Структура

```
main.py              точка входа APK (показывает ошибку, если запуск упал)
app.py               графическое приложение (Kivy)
buildozer.spec       настройки сборки APK
microos/
  kernel.py          ядро: процессы, планировщик, пользователи, журнал
  memory.py          менеджер памяти
  fs.py              виртуальная файловая система
  shell.py           оболочка msh и все команды
  programs.py        фоновые программы
  boot.py            загрузчик
  __main__.py        консольная версия
tests/               тесты (python -m unittest tests.test_microos)
```

Чтобы добавить свою команду, напишите функцию в `microos/shell.py` с декоратором `@command(...)`. Чтобы добавить фоновую программу, напишите генератор в `microos/programs.py`.
