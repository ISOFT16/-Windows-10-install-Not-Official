MicroOS для Windows 7 / 8 / 10 / 11
=====================================

Как запустить:
  MicroOS.exe               - MicroOS с рабочим столом (графика).
  MicroOS (DirectX).bat     - то же самое, если MicroOS.exe не открывается
                              или пишет про OpenGL (старая видеокарта).
  MicroOS-Console.exe       - консольная MicroOS без графики,
                              работает на любом компьютере.

Не удаляйте другие файлы и папки рядом с exe: они нужны для работы.
Диск MicroOS (ваши файлы) хранится в папке %APPDATA%\microos.

Если на Windows 7 появляется ошибка про api-ms-win-crt-*.dll,
установите обновление Windows KB2999226 (Universal C Runtime)
и пакет Microsoft Visual C++ 2015-2022 Redistributable.

Пароль root по умолчанию: root. Список команд: help.
